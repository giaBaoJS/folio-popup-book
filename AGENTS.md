# AGENTS.md

FOLIO: a pop-up storybook for the iPhone Duo. Folded, the cover display shows a closed
hardcover. Unfold the phone and the book opens with it (the book follows the hinge angle);
paper pieces stand up one by one. Pinch into the glowing window and the camera dives through
it into the next chapter, which becomes a normal app screen with a chapter card; every
pinch goes one scene deeper, and the last scene leads back into the book. iOS only.

## Stack (pinned)

- Expo SDK 57, React Native 0.86.3, React 19.2.3, TypeScript 6, bun
- `react-native-skia` 3.1.0 (Graphite on Dawn) + `react-native-webgpu` 0.13.0, sharing one
  `react-native-webgpu-dawn` 154.2.0 and one GPU device
- `react-native-reanimated` 4.7.1, `react-native-worklets` 0.13.0, gesture handler, expo-audio, expo-haptics
- Local Expo module `modules/folio-hinge` (Swift, `UIHingeInteraction`, iOS 27.1) streams the hinge angle.
- `ios/` is generated by prebuild and gitignored; configure through `app.json` and `plugins/`.

## Commands

```sh
bun install
bun run typecheck
bunx expo prebuild --platform ios   # also runs pod install
xcodebuild -workspace ios/Folio.xcworkspace -scheme Folio -configuration Release \
  -sdk iphonesimulator -destination 'id=<UDID>' -derivedDataPath ios/build/dd build
xcrun simctl install <UDID> ios/build/dd/Build/Products/Release-iphonesimulator/Folio.app
xcrun simctl launch --terminate-running-process <UDID> com.giabaojs.folio [-showreel 1] [-chapter 2] [-debug 1]
```

Simulator: create an "iPhone Duo" on the iOS 27.1 runtime and fold/unfold it from the Simulator's
Device menu (or DeviceHub). Flags: `-showreel 1` autopilot through the story, `-chapter N` start
inside chapter N (0-based: `-chapter 2` opens chapter III), `-debug 1` status line, `-mute 1`,
`-nohaptics 1`, `-atlas 1` draw the paper atlas,
`-pattern <id>` draw one atlas pattern, `-stage N` render only the first N passes,
`-testclear 1` clear to red instead of rendering (GPU path check).

Assets:

```sh
bun run scenes -- [--only woods,attic] [--no-preview]   # Blender -> src/assets/scenes/*.ts
bun run sounds                                          # tools/synth.py (python3 + numpy) -> assets/sfx
```

Both are deterministic: rerunning them on unchanged sources rewrites identical files.

Headless (no simulator, macOS only: it loads system fonts): the app's director + WGSL on Dawn in
Node, the atlas on CanvasKit.

```sh
bun run headless -- --shot "woods,cover,woods:p=0.6,attic@4,deep:yaw=0.3" [--out .headless/x]
python3 tools/sheet.py out.png a.png b.png   # needs Pillow
```

The script bundles `tools/headless.ts` with bun and runs it with Node (bun segfaults in the
`webgpu` addon). See `tools/SCENE_GUIDE.md` for how scenes are built.

## Layout

- `src/director/world.ts`: the director (UI runtime). Fold + hinge -> book openness (critically
  damped), pop-up springs, the dive (`tr.p` 0..1 from pinch, tap or autopilot), cameras (cover,
  reading, dive bezier, arrival settle), per-frame uniforms, post blend between scene grades.
  `showreel.ts` is the `-showreel` autopilot.
- `src/story/`: `registry.ts` scene order; `scene_*.ts` per-chapter look, lights, cameras, text,
  actor animation; `rig.ts` book + pop-up mechanics (gutter-split pieces, squash while folded);
  `anim.ts` actor helpers.
- `src/engine/`: `shaders.ts` (paper material, manual PCF shadows, portal, background, particles,
  bloom, composite), `gpu.ts` (pipelines, atlas mips, targets), `render.ts` (per-frame encode:
  inner scene -> outer scene sampling it through the portal -> bloom -> composite), `frame.ts`, `math.ts`.
- `src/art/`: the 4096² paper atlas painted by Skia (`atlas.ts`, `brush.ts`, `paint_*.ts`);
  pattern ids in `patterns.json` (append only).
- `src/ui/Stage.tsx`: GPU setup, Graphite view, frame loop, gestures, hinge, audio bridge.
- `src/ui/overlay.ts`: app chrome drawn by Skia on the UI thread (cover prompt, chapter card
  with ink-wipe text, dots, back button, portal pulse) and its tap targets.
- `src/audio.ts` (music, ambience, cues), `src/flags.ts` (launch flags).
- `tools/blender/`: `kit.py` paper geometry, `props.py`, `book.py`, one file per scene, `export.py`
  (gutter split, AO bake, 28-byte vertex packing).

## Traps

- The iOS simulator's Metal family has no comparison samplers: one in a bind group silently
  drops the whole command buffer (Skia's Dawn device skips validation). Shadows use `textureLoad` PCF.
- Async WebGPU calls (`mapAsync`) never settle on the device imported from Skia; create pipelines
  synchronously.
- Worklet closures are captured when the module evaluates: a worklet calling a helper declared
  later in the same file gets `undefined`. Declare helpers above callers, and give every helper a
  worklet calls its own `'worklet'` directive (the headless renderer cannot catch a missing one).
- WGSL derivatives (`dpdx`, `fwidth`) must run before any non-uniform branch or discard.
